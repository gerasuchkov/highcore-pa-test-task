# Источники привлечения (UA)

Каждый игрок приходит в игру через один из источников установки. Источник зафиксирован в параметре `install_source` всех событий пользователя. Назначение происходит на момент установки и не меняется со временем.

## Каналы

| install_source | Тип | Описание | Месячный бюджет |
|---|---|---|---|
| `organic` | organic | Органический трафик: App Store / Google Play поиск, word-of-mouth, ASO. Стоимость на пользователя ≈ 0. | — |
| `ad_network_1` | paid | Крупная mediation-сеть, преимущественно interstitial-кампании. Стабильный по объёму канал, средний CPI. | основной |
| `ad_network_2` | paid | Performance-сеть с упором на rewarded video. Чаще даёт игроков с высокой готовностью смотреть рекламу. | основной |
| `ad_network_3` | paid | Бид-сеть, экспериментальная для нас. Подключили в этом квартале, ещё не до конца откалибровали аудитории. | средний |
| `ad_network_4` | paid | Нишевая сеть с упором на конкретные жанры. Маленький, но качественный канал. | малый |
| `partner_X` | paid (direct) | Прямой партнёрский канал: offerwall + traffic-deal с большим аффилиатом. Самый дешёвый CPI в портфеле. Подключён давно, спорадически даёт всплески объёма. | большой |
| `cross_promo` | paid (internal) | Кросс-промо из других тайтлов нашего портфеля. Игроки, переходящие из одной игры студии в другую. | малый |

## Распределение установок

Доли каналов в общем потоке installs за окно наблюдения примерно следующие:

- `organic` — около 30%
- `partner_X` — около 25%
- `ad_network_1` / `ad_network_2` — по ~10%
- `ad_network_3` / `ad_network_4` — по 7–8%
- `cross_promo` — около 10%

Эти доли — фактический сплит трафика, а не плановый. Реальные траты на каждый канал и эффективность остаются для отдельного анализа.

## Что важно понимать

- Назначение `install_source` происходит на стороне атрибутора (MMP) и приходит к нам уже готовым. Мы доверяем атрибуции в том виде, в котором она приходит.
- Все события пользователя несут `install_source` как контекст, поэтому фильтрация по каналу делается на уровне любых аналитических разрезов без дополнительных join'ов.
