# Дизайн обучающего туториала

Туториал — это первое, что видит новый игрок после `first_open`. Он состоит из 7 шагов с одной развилкой посередине. По дизайну все шаги обязательны: пройти их можно только последовательно.

## Структура шагов

| Шаг | Название | Что показывается игроку |
|---|---|---|
| 1 | Welcome | Стартовый экран приветствия, краткая история мира |
| 2 | Basics | Базовые правила: чем игрок управляет, как побеждает |
| 3 | Controls | Тач-управление, основные жесты, hint-подсказки |
| 4 | **Choice — выбор стиля игры** | Развилка: игрок выбирает один из трёх предложенных стилей. Дальнейший туториал зависит от выбора. |
| 5 | Practice (зависит от выбора) | Практическая мини-задача в выбранном стиле |
| 6 | Tips | Советы по экономике/прогрессу |
| 7 | Wrap-up | Закрытие туториала, выход в основной экран |

После шага 7 эмитится событие `tutorial_complete` и игрок попадает в обычный игровой цикл.

## Развилка на шаге 4

На 4-м шаге игроку предлагают выбрать один из трёх стилей игры. Этот выбор фиксируется в событии `tutorial_branch_chosen` с параметром `branch`:

| Branch | Стиль | Краткое описание |
|---|---|---|
| `A` | Strategic | Игрок предпочитает обдумывать ходы, видит более крупный board, больше времени на ход |
| `B` | Casual | Сбалансированный режим: средний темп, board стандартного размера |
| `C` | Quick mode | Быстрый темп, компактный board, акцент на короткие сессии |


## События туториала

| event_name | Когда логируется | Параметры |
|---|---|---|
| `tutorial_start` | Перед первым шагом | `session_id` |
| `tutorial_step` | На каждом шаге 1–7 | `session_id`, `step` |
| `tutorial_branch_chosen` | После шага 4 (если игрок дошёл) | `session_id`, `branch` |
| `tutorial_complete` | После шага 7 | `session_id` |

Если игрок выходит из туториала до шага 7, событие `tutorial_complete` не логируется — последним для такого пользователя будет `tutorial_step` с последним пройденным `step`.
